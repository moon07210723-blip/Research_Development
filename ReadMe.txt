# Hearing Rehabilitation Game Project

## プロジェクト概要
/*
UnityとC#を使用して制作した、聴覚リハビリテーションを目的としたゲームプロジェクトです。
3種類のゲームを1つのプロジェクトとして制作しており、メイン画面からプレイしたいゲームを選択できるように構成しました。
既存の聴覚リハビリ用プログラムは、音声を聞いて画面上の正解を選択するテキスト中心のシンプルな形式でした。
そこで、キャラクター操作や戦闘、レベルアップなどのゲーム要素を加えることで、よりゲームとして楽しみながら聴覚トレーニングを行えるようにすることを目的として制作しました。
*/

## Development Environment
/*
- Unity
- C#
- Unity Asset Store Assets
- Unity Asset Store UI Packages
UIの動きを滑らかにする機能など、一部についてはUnity Asset Storeのアセットやパッケージを利用しています。
*/

## ゲーム構成

### 1. OX Quiz
##音声や問題の内容を確認し、OまたはXを選択するクイズ形式のゲームです。

### 2. Word Quiz
##音声を聞き、対応する正しい単語を選択するゲームです。

### 3. Action / Level-up Game
##キャラクターを操作してモンスターと戦いながら進行するゲームです。
##レベルアップ時には音声や単語に関する問題が出題され、正解するとゲームを進めることができます。
##また、レベルアップ後には複数のスキルから自分が使用したいスキルを選択できるようにしました。


## 担当範囲
/*
プログラミングは、自分を含む2名で分担して開発しました。
自分が主に担当した内容は以下の通りです。
- キャラクターの移動処理
- キャラクターの攻撃処理
- GameManagerの実装
- Object Poolの実装
- Spawnerの実装
- OX Quiz関連機能の実装
- ゲーム進行に必要な各種機能の実装
もう1名のプログラマーは、主に以下の部分を担当しました。

- クイズデータとCSVファイルの連携
- UIの配置
- UI関連機能の一部
- UIアニメーション用パッケージとの連携
一部の機能については、互いに作成した機能を連携させながら共同で開発しています。
*/


## デザイン・アセット
/*
ゲーム内で使用している一部のグラフィック素材は、Unity Asset Storeなどから購入またはダウンロードした素材を使用しています。
使用するゲームの雰囲気に合わせるため、必要に応じて素材にドット絵加工などを行いました。
UIの構成やゲーム内で使用する素材については、チーム内で調整しながら制作しました。
*/


## 工夫した点
/*
既存の聴覚リハビリ用プログラムでは、音声を聞いて正解を選択することが中心であり、ゲームとしての操作要素は限られていました。
本プロジェクトでは、単純に問題へ回答するだけではなく、キャラクターの移動、戦闘、レベルアップ、スキル選択などの要素と聴覚問題を組み合わせました。
これにより、問題への回答そのものをゲーム進行の一部として組み込み、継続してプレイしやすい構成を目指しました。
*/

## 学んだこと
/*
複数のゲームシステムを1つのプロジェクト内で管理する経験を通して、GameManagerを利用したゲーム進行の管理や、Object Pool、Spawnerなどを利用したオブジェクト管理について理解を深めました。
また、2名のプログラマーがそれぞれ担当した機能を組み合わせる必要があったため、自分が作成した機能だけでなく、他のメンバーが作成した処理との連携を考えながら開発する経験を得ることができました。*/
